🚀 ToOffice

Эксклюзивное окружение для локального запуска десктопного Microsoft Office 2021 на Linux Mint

Скачать .DEB пакет

📋 О проекте

ToOffice — это легковесная open-source утилита, которая изолирует оригинальные бинарные файлы Microsoft Word 2021 и разворачивает локальную фоновую службу RPC-запросов для автоматической проверки лицензии. Больше никаких тяжелых виртуальных машин!

⚡ Особенности

  • **Быстрый запуск:** Открытие оригинального Word 2021 прямо в графическом окружении Linux Mint.
  • **Автономная активация:** Встроенная фоновая Linux-служба для эмуляции RPC-сервера проверки ключей.
  • **Полная интеграция:** Автоматическое добавление ярлыка запуска в системное меню «Офис».

💻 Установка через терминал

Если вы предпочитаете устанавливать пакеты вручную, выполните следующие команды:

git clone https://github.com
cd ToOffice
sudo apt install ./tooffice.deb
