# ToOffice (for Linux Mint)

Утилита автоматической настройки системных окружений и служб для локального запуска десктопного Microsoft Office 2021 на операционной системе Linux Mint.

## 🛠 Возможности
- Полная автономная работа без развертывания тяжелых виртуальных машин.
- Встроенная локальная фоновая служба обработки RPC-запросов для проверки лицензий.
- Интеграция ярлыка запуска прямо в системное меню «Офис».

## 📦 Сборка пакета из исходного кода
Вы можете самостоятельно собрать установочный `.deb` файл на своем компьютере:

```bash
git clone https://github.com/damiry947/ToOffice
cd ToOffice
chmod +x build_deb.sh
./build_deb.sh
```

После этого установите полученный пакет через `gdebi` или командой:
```bash
sudo apt install ./tooffice.deb
```
