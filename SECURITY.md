# Политика безопасности ToOffice

## Поддерживаемые версии
В настоящее время обновления безопасности и исправления ошибок выпускаются только для текущей версии приложения.

| Версия | Поддержка |
| ------- | ---------- |
| 1.0.0   | ✅ Да      |

## Как сообщить об уязвимости
Если вы обнаружили критическую ошибку безопасности или уязвимость в скриптах запуска или работе фоновой службы RPC, пожалуйста, не создавайте публичный баг-репорт в разделе Issues. 

Вместо этого сообщите о проблеме разработчику напрямую, создав приватный отчет на вкладке Security на GitHub или связавшись по электронной почте.
